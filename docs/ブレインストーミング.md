# ブレインストーミング

- ドキュメントの穴埋めをすることで学習するアプリを作りたい
- Github Pages にデプロイして、どこでもアクセスできるようにしたい
- DBはsupabaseがいいかな？
- フロントはReact/vite
- CSSは素のtailwindかshadcn?とかを考えている
- ID/password で認証したい
- 画面構成はこんな感じ？
  - ログイン画面
  - 科目一覧画面
  - 教材一覧画面
  - 教材編集画面
  - 解答画面
  - 学習履歴画面
- ドキュメントの中に空欄とする箇所を埋め込む
- 教材編集画面では空欄が埋め込まれたドキュメントをそのまま編集できる（プレビューもできる）
- ドキュメントはmd形式で画像やテーブルなどもレンダリングできる
- 空欄に入るワード（以下キーワードと呼ぶ）とそのIDをドキュメントに埋め込み、それをDBのワード列と対応させる
- IDが入っていない場合は自動で採番する（連番ではなく乱数がいいかな？）
- ドキュメントは章立てにでき、章ごとに編集する
- 章はネスト可能
- 解答開始時に、科目全体・教材ごと・章ごとで出題範囲を選択する
- キーワードはタグ付け可能にして、出題時に表示している範囲内で同じタグのキーワードは非表示にする
- 出題時に表示する範囲は解答者が拡張可能にする（デフォルトは章単位とか？）
- ドキュメントはインポート・エクスポート可能にする
  - 章の階層はフォルダ構成で表して、zipでエクスポートするとか？
- 解答形式は選択肢と記述完全一致
- 誤答選択肢もキーワードと一緒にドキュメントに埋め込み可能とし、ない場合は同じ章の同じタグのキーワードから選ぶ
- 正誤判定で間違いだった場合、解答した内容を別解に登録可能にする
- 出題順は、自動・先頭から の2つとする
- 自動は、未出題・正答率・同じ問題の連続などを考慮した優先度を設定する
- 仕様は決定表形式で書く
  - 観点ごとに決定表を作成
  - 条件・操作・結果・ユニットテスト・E2Eテスト の5ブロック
  - 行がブロックの要素、列は1条件を表し、1列1assertになるようにしたい
  - セルには○・×・空欄のどれかが入る
  - 行タイトルは2列になってもよい（出題順：自動と出題順：先頭から など）
  - 実体はjsonlで1列1行で持ち、○×ではなく行タイトルをそのまま持つ（gitの差分がわかりやすかったり、AIが読みやすくするため）
  - 表示用のhtmlをjsonlからスクリプトで生成する
    - htmlでは各テーブルの上に列番号を入力するとその列に関係のある行だけが表示されるような数値入力欄をつける
