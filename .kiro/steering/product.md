# プロダクト概要

「穴埋め学習」は、利用者が Markdown で作成したノートを、その文脈を保ったまま穴埋め問題へ変換し、間隔反復で定着させる個人学習アプリである。単語帳を別に作るのではなく、ノート本文に埋め込んだキーワードを直接出題対象にする。

## 中核価値

- ノート作成と問題作成を一体化し、教材作成の二重作業を減らす
- 章や周辺文章を見ながら解くことで、語句を文脈と結び付けて覚える
- 未出題・復習期限・習熟度に応じて、今解くべき問題へ集中する
- 習熟後は選択式から記述式へ移行し、想起の難度を段階的に上げる
- 教材を Markdown ベースの zip で持ち運び、サービスに閉じ込めない

## 中核機能

- 科目、教材、ネスト可能な章による教材整理
- Markdown 編集、プレビュー、キーワード記法とキーワードマスタの同期
- 選択式・記述式・自動切替による穴埋め学習
- SM-2 相当の間隔反復、別解登録、解答履歴の記録
- 階層別達成度、苦手キーワード、日別学習量の可視化
- 教材単位の zip エクスポートと、教材・章単位のインポート

## 対象利用者と利用場面

主対象は、自分で教材を作成・整理し、PC とスマートフォンから反復学習する個人学習者である。アカウントは管理者が発行し、利用者ごとの教材と学習履歴は互いに分離する。

代表的な流れは、ログイン、教材作成、Markdown 本文のキーワード化、出題範囲と形式の設定、解答、SRS 更新、学習履歴の確認である。

## プロダクト原則

- 教材本文を一次的な学習文脈として扱う
- キーワードの実体は DB で一元管理し、本文は安定した文書内 ID で参照する
- 教材編集後も、可能な限りキーワードの学習履歴を継続する
- 削除、上書き、インポートでは影響を事前に示し、破壊的な選択を利用者に委ねる
- 通信失敗や中断で、編集内容や記録済みの学習結果を不必要に失わせない
- モバイル対応、ライト／ダークテーマ、十分なコントラストと操作領域を維持する
- 1,000 件の API 取得上限を超えるデータでも、一覧、集計、出題、出力を欠落させない

## 対象外

- 公開サインアップ、共同編集、教材マーケット、公開プロフィール
- AI 採点、部分一致や意味類似による曖昧判定
- 科目をまたぐ教材移動、教材をまたぐ章移動
- 画像のプレビュー、zip への画像同梱、学習履歴のエクスポート
- 専用アプリサーバー、オフライン同期

## 仕様の位置づけ

今後の要求、設計、実装計画の正は `.kiro/specs/` とし、プロジェクト横断の判断基準は `.kiro/steering/` に置く。既存の `spec/tables/*.jsonl` は、移行時点の詳細な振る舞いとテスト対応を保持する回帰資産として維持する。新しい振る舞いは cc-sdd の承認済み仕様を先に更新し、必要な決定表・テスト・コードを同じ変更で追従させる。
