# 要求仕様書

## はじめに

教材ポータビリティは、個人学習者が教材の章構造と Markdown 本文を zip として持ち出し、同じ契約の zip を新しい教材または既存教材の章配下へ安全に取り込むための機能である。本仕様は既存の transfer／editor／shared 実装、import RPC migration、29列の回帰決定表、ユニットテスト、E2E テストで確認できる振る舞いを、今後の機能追加が依存できるベースラインとして定義する。

## 境界コンテキスト

- **対象**: 教材単位の zip エクスポート、章階層と順序のファイル表現、Markdown 本文とキーワード記法の展開、教材／章単位の zip インポート、章ツリー復元、文書内 ID の採番、キーワード突合、差分確認、原子的な取り込み、入出力エラー、取得上限を超える出力の完全性
- **対象外**: 学習履歴・SRS 状態・画像・内部 DB ID の zip 収録、教材間の直接移動、部分的な取り込み、クラウド同期、zip 以外の交換形式、Markdown 画像の表示
- **隣接する期待**: 教材・章の存在、所有者、親子関係、保存順と取得上限を超える全件読み取りは `learning-content-catalog` に依存する。キーワード記法、文書内 ID、本文の縮約／展開、正答正規化、重複／衝突判定と履歴継続性は `markdown-keyword-authoring` の契約を利用する。共通ダイアログと操作中ガードは `app-shell-and-responsive-experience` に依存し、取り込み後の編集と学習は本仕様が返す教材 ID と保存済みデータを利用する。

## 要求

### Requirement 1: 教材 zip と章階層のエクスポート

**目的:** 個人学習者として、教材の章構造と順序を再構築できる zip を取得したい。それにより、教材をサービス外へ持ち出せる。

#### 受入基準

1. When 利用者が教材のエクスポートを実行する, the 教材ポータビリティ shall 教材名を基にした `.zip` ファイルをダウンロードする
2. When 教材に親章と子章がある, the 教材ポータビリティ shall 親章をフォルダ、親章自身の本文をそのフォルダの `index.md`、子章を配下の Markdown ファイルまたはフォルダとして表す
3. When 同じ親を持つ章を書き出す, the 教材ポータビリティ shall 保存済みの兄弟順を連番プレフィックスとしてフォルダ名またはファイル名へ付ける
4. When 同じ親に同名の章が複数ある, the 教材ポータビリティ shall 連番プレフィックスにより各章を別のパスとして保持する
5. When 教材名または章タイトルにファイル名として使えない文字がある, the 教材ポータビリティ shall zip とパスの名前だけを安全な文字へ置き換え、章本文の文字列は変更しない
6. If 教材に章が1件もない, the 教材ポータビリティ shall エクスポートを完了せず理由を利用者へ表示する
7. The 教材ポータビリティ shall zip に教材のメタ情報ファイル、学習履歴または画像を含めない

### Requirement 2: Markdown 本文とキーワードの完全なエクスポート

**目的:** 個人学習者として、編集可能なキーワード情報を含む Markdown を欠落なく取得したい。それにより、出力先でも教材内容を復元できる。

#### 受入基準

1. When 章本文に登録済みキーワードの文書内 ID が現れる, the 教材ポータビリティ shall 章内の最初の出現を正答、文書内 ID、タグおよび誤答選択肢を持つ形式へ展開し、同じ章内の2回目以降は文書内 ID だけの形式を保つ
2. While キーワードがいずれの章本文にも現れない, the 教材ポータビリティ shall そのキーワードを zip へ追加しない
3. When 教材にキーワードが1件もない, the 教材ポータビリティ shall 章の Markdown 本文だけをエクスポートする
4. When エクスポート対象のキーワードが1回の取得上限を超える, the 教材ポータビリティ shall すべてのキーワードを取得し、本文に残る文書内 ID を可能な限り展開する
5. When エクスポート対象の章が1回の取得上限を超える, the 教材ポータビリティ shall すべての章を zip に含める
6. If 教材または出力に必要なデータを取得できない, the 教材ポータビリティ shall エクスポートを完了せず操作文脈を含むエラーを利用者へ表示する

### Requirement 3: zip からの章ツリー復元と取り込み先

**目的:** 個人学習者として、zip の Markdown 構造を新規教材または既存教材の章として取り込みたい。それにより、用途に応じた単位で教材を再利用できる。

#### 受入基準

1. When 利用者が科目で zip を教材として取り込む, the 教材ポータビリティ shall 選択中の科目へ zip ファイル名から `.zip` を除いた名前の新しい教材を作る
2. When 取り込み先の科目に同名教材がある, the 教材ポータビリティ shall 既存教材へ統合せず別の教材を作る
3. When 利用者が教材編集画面で zip を章として取り込む, the 教材ポータビリティ shall 新しい教材を作らず、選択中の章の配下へ zip の最上位章を作る
4. When zip のパスに連番プレフィックスがある, the 教材ポータビリティ shall 連番順を章の兄弟順に使い、章タイトルからプレフィックスを除く
5. When zip の同じ階層に連番プレフィックスのないパスがある, the 教材ポータビリティ shall パス名の昇順を章の兄弟順に使う
6. When フォルダに `index.md` がある, the 教材ポータビリティ shall その内容をフォルダに対応する章自身の本文にする
7. When Markdown ファイルを含むフォルダに `index.md` がない, the 教材ポータビリティ shall 空の本文を持つ章としてそのフォルダを作る
8. When zip が複数階層のフォルダを持つ, the 教材ポータビリティ shall その階層を章の親子関係として復元する
9. If zip に Markdown ファイルが1件もない, the 教材ポータビリティ shall データを変更せず取り込める章がない旨を表示する
10. If 選択した zip を展開できない, the 教材ポータビリティ shall データを変更せず読み込めない旨を表示する

### Requirement 4: 取り込み本文と文書内 ID の正規化

**目的:** 個人学習者として、取り込んだキーワード記法を既存教材と一貫した保存形式にしたい。それにより、編集と学習の契約を継続できる。

#### 受入基準

1. When 取り込むキーワード記法に文書内 ID がないまたは規約外の ID がある, the 教材ポータビリティ shall 取り込み先教材の既存 ID および同じ取り込み内で先に割り当てた ID と衝突しない規約内 ID を割り当てる
2. When 取り込むキーワード記法に規約内の文書内 ID がある, the 教材ポータビリティ shall その ID を保持して既存キーワードとの突合へ渡す
3. When 取り込みを確定する, the 教材ポータビリティ shall すべての有効なキーワード記法を文書内 ID だけの保存形式へ縮約して章本文を保存する
4. When 取り込むキーワード記法が正答、タグまたは誤答選択肢を持つ, the 教材ポータビリティ shall それらを同じキーワードの内容として取り込む
5. When 同じ文書内 ID が複数の取り込み章本文に現れる, the 教材ポータビリティ shall 各本文中の出現を章との所属として保存し、最初に定義を取り込んだ章はキーワードの起源情報としてのみ記録する

### Requirement 5: 既存キーワードとの突合

**目的:** 個人学習者として、取り込み内容と登録済みキーワードを一貫した規則で突合したい。それにより、履歴を継続しつつ意図しない上書きを避けられる。

#### 受入基準

1. When 取り込むキーワードに割り当てた文書内 ID が取り込み先に存在しない, the 教材ポータビリティ shall そのキーワードを新規登録対象にする
2. When 取り込む文書内 ID が既存キーワードと一致し、両者の正答が正規化後に1件以上一致する, the 教材ポータビリティ shall 差分確認を挟まず正答、タグおよび誤答選択肢を取り込み内容で置き換える
3. When 既存キーワードを取り込み内容で置き換える, the 教材ポータビリティ shall キーワードの識別子、解答履歴および SRS 状態を継続する
4. If 取り込む文書内 ID が既存キーワードと一致しても正答が正規化後に1件も一致しない, the 教材ポータビリティ shall そのキーワードを自動で上書きせず差分確認へ表示する
5. If 同じ zip 内の同一文書内 ID に異なる内容が複数ある, the 教材ポータビリティ shall 登録済み内容があればそれを含む相異なる全候補を差分確認へ表示し、利用者が候補を1件選ぶまでその ID を適用しない
6. When 同じ zip 内の同一文書内 ID に同じ内容が複数ある, the 教材ポータビリティ shall 差分確認を表示せず1件の適用対象として扱う
7. While 差分確認が必要なキーワードが0件である, the 教材ポータビリティ shall 利用者へ追加確認を求めず取り込みを完了する

### Requirement 6: 差分確認と利用者選択

**目的:** 個人学習者として、食い違うキーワードごとに登録済み内容と取り込み内容を比較して選びたい。それにより、上書きの判断を自分で制御できる。

#### 受入基準

1. When 差分確認を表示する, the 教材ポータビリティ shall 文書内 ID、登録済み候補（存在する場合）および重複を除いた全取り込み候補の正答をキーワードごとに示す
2. When 差分確認を最初に表示する, the 教材ポータビリティ shall 登録済み候補があればそれを既定にし、登録済み候補がなければ最初の取り込み候補を既定にする
3. When 利用者が取り込み候補を1件選んで適用する, the 教材ポータビリティ shall 対象キーワードの正答、タグおよび誤答選択肢を選択した取り込み内容で置き換える
4. When 利用者が登録済み内容を残して適用する, the 教材ポータビリティ shall 対象キーワードの登録済み内容を変更しない
5. If 利用者が差分確認を取り消す, the 教材ポータビリティ shall 取り込みを確定せず対象データを変更しない
6. While 取り込みを処理している, the 教材ポータビリティ shall 適用操作を無効にして処理中であることを示す

### Requirement 7: 原子的な取り込みと往復互換性

**目的:** 個人学習者として、教材とキーワードを中途半端な状態にせず取り込みたい。それにより、通信失敗後も既存データを信頼できる。

#### 受入基準

1. When 取り込みが成功する, the 教材ポータビリティ shall 対象教材、章階層、縮約本文および選択済みキーワード変更を一体として反映する
2. If 取り込み処理の一部で失敗する, the 教材ポータビリティ shall 教材、章およびキーワードのいずれにも部分的な変更を残さず失敗を表示する
3. If 取り込み先として認証利用者が所有しない科目、教材または親章が指定される, the 教材ポータビリティ shall 対象データを変更せず取り込みを拒否する
4. When 新しい教材を取り込む, the 教材ポータビリティ shall 同じ科目の教材一覧末尾にその教材を配置する
5. When 既存教材へ同じ文書内 ID のキーワードを上書きする, the 教材ポータビリティ shall 新しいキーワードを重複作成せず既存キーワードを更新する
6. When エクスポートした zip を同じ教材へ章として取り込む, the 教材ポータビリティ shall 差分確認を要求せずキーワード内容と学習履歴を継続する
7. When 取り込みが成功する, the 教材ポータビリティ shall 取り込み先教材の識別子を後続画面へ返し、最新の教材または章一覧を表示できるようにする
