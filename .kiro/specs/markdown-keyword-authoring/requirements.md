# 要求仕様書

## はじめに

Markdown キーワード編集は、個人学習者がノート本文の文脈を保ったまま語句を空欄化し、安定した文書内 ID を通じてキーワードマスタと学習履歴を継続するための機能である。本仕様は既存の editor／lib コード、DB migration、決定表 05〜09、ユニットテスト、editor E2E、編集画面ワイヤーフレームで確認できる振る舞いを、今後の機能追加が依存できるベースラインとして定義する。

## 境界コンテキスト

- **対象**: Markdown 本文の編集とプレビュー、キーワード記法の解析と整形、選択範囲からの作成、既存キーワードの編集と解除、文書内 ID の検証と採番、保存用本文への縮約と編集用本文への展開、キーワードマスタ更新、正答衝突の解決、未使用キーワードの活性同期、章削除確認用の本文出現数算出、章削除完了後の残存本文に基づく活性再同期、未保存離脱保護、保存の二重送信防止、1回の取得上限を超える同期
- **対象外**: 科目・教材・章そのものの CRUD、削除 transaction と並べ替え、zip の構造と入出力、出題候補の選択・採点・SRS 更新、画像の描画と管理、共同編集、曖昧採点
- **隣接する期待**: 教材と章の存在・所有権・選択順、および取得上限を超える全件読み取りは `learning-content-catalog`、共通シェル、共通ダイアログ、操作中ガードとテーマは `app-shell-and-responsive-experience` に依存する。`material-portability` は本仕様のキーワード記法、正答正規化、文書内 ID、重複／衝突判定を利用し、`adaptive-study-session` は本仕様が維持するキーワード内容、文書内 ID、活性状態、履歴継続性を利用する。

## 要求

### Requirement 1: Markdown 編集とプレビュー

**目的:** 個人学習者として、本文と描画結果を並べて確認しながら Markdown を編集したい。それにより、学習文脈を壊さずに教材を作成できる。

#### 受入基準

1. When 利用者が章を選ぶ, the Markdown キーワード編集 shall キーワード内容を展開した本文を編集領域へ表示し、対応する Markdown プレビューを表示する
2. When 利用者が本文を書き換える, the Markdown キーワード編集 shall プレビューを入力へ追随させ、未保存の変更があることを表示する
3. When 本文に見出し、段落、改行、箇条書き、番号付き箇条書き、引用、コード、強調、リンクまたは表がある, the Markdown キーワード編集 shall 対応する構造としてプレビューへ表示する
4. When 本文に認識可能なキーワード記述がある, the Markdown キーワード編集 shall その箇所を正答付きの操作可能な空欄としてプレビューへ表示する
5. When 本文に画像記法がある, the Markdown キーワード編集 shall 画像として描画せず記法を文字列のまま保持する
6. While 章が選ばれていない, the Markdown キーワード編集 shall 章の選択を促し、編集領域を表示しない
7. When 編集領域に認識可能なキーワード記述がある, the Markdown キーワード編集 shall その記述を本文の他の部分と区別して表示する
8. While 画面幅が広い, when 利用者が編集領域またはプレビューをスクロールする, the Markdown キーワード編集 shall 両者のスクロール割合を同期し、章ツリーのスクロールを独立させる
9. While 画面幅が狭い, the Markdown キーワード編集 shall 章、編集、プレビューをタブで切り替えられるようにする

### Requirement 2: キーワードの作成・編集・解除

**目的:** 個人学習者として、本文またはプレビューから語句を選び、キーワードの正答・タグ・誤答選択肢を編集したい。それにより、本文の流れの中で問題情報を管理できる。

#### 受入基準

1. When 利用者がプレビューまたは編集領域の文字列を選択してキーワード作成を選ぶ, the Markdown キーワード編集 shall 選択文字列を最初の正答にした編集ダイアログを表示する
2. If 文字列が選択されていない, the Markdown キーワード編集 shall キーワード作成を受け付けない
3. If 選択範囲が既存のキーワード記述と重なる, the Markdown キーワード編集 shall 入れ子になるキーワード作成を受け付けない
4. When 利用者がプレビューの空欄を選ぶ, the Markdown キーワード編集 shall 本文またはキーワードマスタにある正答、タグ、誤答選択肢を編集ダイアログへ表示する
5. If 編集ダイアログの正答が0件である, the Markdown キーワード編集 shall 確定を受け付けない
6. When 利用者が正答を1件以上指定して編集ダイアログを確定する, the Markdown キーワード編集 shall 本文の対象範囲だけをキーワード記述へ置き換え、保存操作まではキーワードマスタを変更しない
7. If 利用者が編集ダイアログをキャンセルする, the Markdown キーワード編集 shall 本文を変更しない
8. When 利用者が既存キーワードの解除を選ぶ, the Markdown キーワード編集 shall 記述を外し、最初の正答を通常の本文へ戻す
9. When 利用者が誤答選択肢を空にして確定する, the Markdown キーワード編集 shall 空の誤答選択肢を保持し、下流の出題機能が同じタグから候補を集められる状態にする

### Requirement 3: キーワード記法の解釈と整形

**目的:** 個人学習者として、可搬性のある一貫した記法でキーワードを直接編集したい。それにより、手入力や貼り付けでも意味を失わずに保存できる。

#### 受入基準

1. When `{{正答|id=文書内ID|tags=タグ|wrong=誤答}}` 形式を解釈する, the Markdown キーワード編集 shall 正答、文書内 ID、タグ、誤答選択肢をそれぞれ読み取る
2. When `id`、`tags`、`wrong` が異なる順序で記述される, the Markdown キーワード編集 shall セグメント順序に依存せず同じ内容として扱う
3. When `{{id=文書内ID}}` 形式を解釈する, the Markdown キーワード編集 shall 正答を更新せず既存キーワードへの参照として扱う
4. When カンマ、パイプまたは引用符を含む値が引用される, the Markdown キーワード編集 shall 区切り文字を値の一部として扱い、連続する引用符を1つの引用符として扱う
5. When 区切り文字を含む値が引用されていない, the Markdown キーワード編集 shall その文字を値またはセグメントの区切りとして扱う
6. If 記述が空で文書内 ID もない、閉じ括弧がない、または改行をまたぐ, the Markdown キーワード編集 shall キーワードとして認識せず本文の文字列として保持する
7. When 記述に未知のキーがある, the Markdown キーワード編集 shall 未知のキーを無視して既知の内容を読み取る
8. When 同じキーが複数回指定される, the Markdown キーワード編集 shall 最後に指定された値を採用する
9. When 値の前後に空白、空要素または重複要素がある, the Markdown キーワード編集 shall 前後空白と空要素を除き、同じ値を最初の1件へまとめる
10. When キーワード記述を整形する, the Markdown キーワード編集 shall 正答、文書内 ID、タグ、誤答選択肢の順に並べ、空の任意項目を省略し、区切り文字を含む値を安全に引用する

### Requirement 4: 文書内 ID の検証と採番

**目的:** 個人学習者として、教材内で安定した ID によりキーワードと履歴を結び付けたい。それにより、本文編集後も同じ学習対象を継続できる。

#### 受入基準

1. When 文書内 ID を持たない正答付き記述を保存する, the Markdown キーワード編集 shall 小文字英数字6桁の ID を採番し、本文へ書き足してキーワードを新規登録する
2. When 規約に合う文書内 ID が教材内にまだ存在しない, the Markdown キーワード編集 shall 記述された ID で新しいキーワードを登録する
3. When 規約に合う文書内 ID が同じ教材に既に存在する, the Markdown キーワード編集 shall 既存キーワードへの参照として扱い、そのキーワードの学習履歴を継続する
4. If 生成した文書内 ID が同じ教材の既存 ID または同じ保存内で先に生成した ID と衝突する, the Markdown キーワード編集 shall 未使用の値を得るまで採番し直す
5. When 同じ文書内 ID が別の教材だけに存在する, the Markdown キーワード編集 shall 現在の教材では新しいキーワードとして扱う
6. If 記述された文書内 ID が小文字英数字6桁でない, the Markdown キーワード編集 shall 規約に合う ID を採番し直して本文を書き換える

### Requirement 5: 保存形式・展開形式と活性同期

**目的:** 個人学習者として、本文とキーワードマスタを一貫して保存し、本文から外した語の履歴を残したい。それにより、編集の可読性と永続データの一元性を両立できる。

#### 受入基準

1. When 正答付きのフル形式を含む本文を保存する, the Markdown キーワード編集 shall キーワードマスタへ内容を反映し、保存本文にある文書内 ID 付き記述をすべて ID 参照形式へ縮約する
2. When 同じ文書内 ID が同じ章に複数回現れる, the Markdown キーワード編集 shall 保存本文の全出現を ID 参照形式にし、キーワードマスタでは1件のキーワードとして扱う
3. When 保存本文を編集用に開く, the Markdown キーワード編集 shall 章内の同じ文書内 ID の最初の出現だけをキーワードマスタの内容で展開し、2回目以降を ID 参照形式のままにする
4. When キーワードが教材内のどの本文にも現れなくなる, the Markdown キーワード編集 shall キーワードと学習履歴を削除せず非活性にする
5. When 非活性なキーワードの文書内 ID が本文へ再び現れる, the Markdown キーワード編集 shall キーワードを活性に戻し、既存の学習履歴を継続する
6. While キーワードが非活性である, the Markdown キーワード編集 shall 下流の出題機能がそのキーワードを出題対象から除外できる状態を提供する
7. When 教材の章またはキーワードが1回の取得件数上限を超える, the Markdown キーワード編集 shall 全章の本文と全キーワードを欠落なく扱って活性状態を同期する
8. When 同じ文書内 ID が複数の章本文に現れる, the Markdown キーワード編集 shall 各本文中の出現を章との所属として扱い、キーワードに記録された起源章だけを唯一の所属章として扱わない
9. When 章の削除が完了する, the Markdown キーワード編集 shall 削除後に残る全章本文の文書内 ID を再評価し、1章以上に残るキーワードを活性のまま維持し、どの章にも残らないキーワードを履歴を削除せず非活性にする
10. When 削除対象の章 ID と本文が章削除確認のために渡される, the Markdown キーワード編集 shall キーワードに記録された起源章ではなく、対象本文に現れる有効な文書内 ID のトークン出現数を章出現単位で算出して返す

### Requirement 6: 正答衝突の解決

**目的:** 個人学習者として、既存 ID と異なる内容を貼り付けたときに意図を確認したい。それにより、誤った上書きでキーワードと学習履歴の意味を変えずに済む。

#### 受入基準

1. When 利用者がキーワード編集ダイアログで既存キーワードを変更して保存する, the Markdown キーワード編集 shall 差分確認を挟まず内容を上書きし、既存の学習履歴を継続する
2. When 本文の直接編集後も登録済み正答と1件以上が一致する, the Markdown キーワード編集 shall 差分確認を挟まず内容を上書きし、既存の学習履歴を継続する
3. If 本文の直接編集による正答が登録済み正答と1件も一致しない, the Markdown キーワード編集 shall 一致しないキーワードだけを差分確認へ表示し、自動では上書きしない
4. When 利用者が差分確認で取り込んだ内容を選んで適用する, the Markdown キーワード編集 shall キーワードマスタを上書きし、既存の学習履歴を継続する
5. When 利用者が差分確認で登録済み内容を残して適用する, the Markdown キーワード編集 shall キーワードマスタを上書きせず、編集本文を登録済み内容へ戻す
6. If 同じ保存内の同一文書内 ID に異なるフル形式が複数ある, the Markdown キーワード編集 shall 登録済み内容があればそれを含む相異なる全候補を差分確認へ表示し、利用者が候補を1件選ぶまで本文とキーワードマスタを保存しない
7. If 利用者が差分確認をキャンセルする, the Markdown キーワード編集 shall 本文とキーワードマスタを保存せず未保存状態を維持する
8. When 利用者が本文の文書内 ID を別の規約内 ID へ書き換えて保存する, the Markdown キーワード編集 shall 別のキーワードとして新規登録し、元のキーワードの学習履歴を元の ID に残す

### Requirement 7: 保存中断と離脱からの保護

**目的:** 個人学習者として、失敗、重複操作または意図しない離脱で編集内容を失いたくない。それにより、保存を安全に再試行できる。

#### 受入基準

1. While 本文に変更がない, the Markdown キーワード編集 shall 保存操作を受け付けず永続データを更新しない
2. When 利用者が空の本文を保存する, the Markdown キーワード編集 shall 空の本文として保存する
3. If 保存処理の途中で通信または永続化が失敗する, the Markdown キーワード編集 shall 失敗を表示し、編集中の本文と未保存状態を維持し、章本文・キーワード内容・活性状態に部分更新を残さない
4. When 未保存の変更がある状態で別の章を選ぶ, the Markdown キーワード編集 shall 編集に戻るか変更を破棄して移動するかを確認する
5. When 未保存の変更がある状態でブラウザから離れようとする, the Markdown キーワード編集 shall 離脱確認を表示する
6. While 保存処理が進行中である, when 利用者が保存を再度実行する, the Markdown キーワード編集 shall 同じ保存要求を重複して送信しない
